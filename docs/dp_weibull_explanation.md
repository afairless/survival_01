# Dirichlet Process Draws for the Kottas Weibull Mixture

This note explains how to generate realisations of the mixing distribution
\(G\) in the Weibull Dirichlet process mixture of Kottas (2002), Section 4.1,
and clarifies the Weibull parameterisation used by the paper.

The accompanying implementation is in `src/dp_weibull.py`. The original
simulation code in `src/kottas_2002_5_1.py` is left unchanged.

## 1. Model and notation

The hierarchical model is

$$
\begin{aligned}
t_i \mid \alpha_i,\lambda_i
  &\sim \operatorname{Weibull}(\alpha_i,\lambda_i), \\
(\alpha_i,\lambda_i)\mid G
  &\sim G, \\
G \mid \nu,\gamma,\phi
  &\sim \operatorname{DP}\!\left(\nu G_0(\cdot\mid \phi,\gamma)\right),\\
\nu &\sim \operatorname{Gamma}(a_\nu,b_\nu),\\
\gamma &\sim \operatorname{Gamma}(a_\gamma,b_\gamma),\\
\phi &\sim \operatorname{Pareto}(a_\phi,b_\phi).
\end{aligned}
$$

Here \(G\) is the **mixing distribution over Weibull parameters**, not the
survival distribution itself. The induced survival distribution is

$$
S(t;G)
=
\int K_W(t\mid \alpha,\lambda)\,G(d\alpha,d\lambda),
$$

where the paper's Weibull distribution function is

$$
K_W(t\mid \alpha,\lambda)
=
1-\exp\!\left(-\frac{t^\alpha}{\lambda}\right).
$$

Equivalently, if

$$
G=\sum_{j=1}^{\infty} w_j\,\delta_{(\alpha_j,\lambda_j)},
$$

then

$$
S(t;G)
=
\sum_{j=1}^{\infty}
w_j\exp\!\left(-\frac{t^{\alpha_j}}{\lambda_j}\right).
$$

## 2. The base measure \(G_0\)

The paper chooses

$$
G_0(\alpha,\lambda\mid \phi,\gamma)
=
\operatorname{Uniform}(\alpha\mid 0,\phi)\,
\operatorname{InvGamma}(\lambda\mid d,\gamma),
\qquad d=2.
$$

Therefore an atom \((\alpha_j,\lambda_j)\) is generated by

$$
\alpha_j \sim \operatorname{Uniform}(0,\phi),
\qquad
\lambda_j \sim \operatorname{InvGamma}(\text{shape}=d,\ \text{scale}=\gamma).
$$

In SciPy,

```python
alpha = rng.uniform(0.0, phi, size=n)
lam = invgamma.rvs(a=d, scale=gamma, size=n, random_state=rng)
```

Equivalently, using only NumPy,

```python
alpha = rng.uniform(0.0, phi, size=n)
lam = 1.0 / rng.gamma(shape=d, scale=1.0 / gamma, size=n)
```

The second form follows from the inverse-gamma construction: if
\(X\sim\operatorname{Gamma}(d,1/\gamma)\), then \(1/X\sim
\operatorname{InvGamma}(d,\gamma)\).

## 3. Stick-breaking construction

A Dirichlet process is a distribution over probability measures. A draw from
it is almost surely discrete, and the Sethuraman (1994) stick-breaking
construction represents it as

$$
G=\sum_{j=1}^{\infty} w_j\,\delta_{\theta_j},
\qquad
\theta_j=(\alpha_j,\lambda_j),
$$

where

$$
z_j\sim\operatorname{Beta}(1,\text{precision}),
\qquad
w_1=z_1,
\qquad
w_j=z_j\prod_{s=1}^{j-1}(1-z_s),
$$

and

$$
\theta_j\sim H \quad \text{independently}.
$$

For the prior draw,

$$
\operatorname{precision}=\nu,
\qquad
H=G_0(\cdot\mid \phi,\gamma).
$$

The first few weights tend to be large when \(\nu\) is small, producing a
sparse mixture with few effective components. Larger \(\nu\) produces many
small weights and a realisation closer to \(G_0\).

## 4. Truncating the infinite sum

The paper truncates at \(J\) terms and chooses \(J\) so that the expected
remaining stick-breaking mass is at most \(\epsilon\):

$$
\left(\frac{\text{precision}}{\text{precision}+1}\right)^J
=
\epsilon.
$$

Thus

$$
J=
\left\lceil
\frac{\log\epsilon}
     {\log\!\left(\frac{\text{precision}}{\text{precision}+1}\right)}
\right\rceil.
$$

The paper uses \(\epsilon=10^{-4}\). The last weight is set to the residual
mass,

$$
w_J = 1-\sum_{j=1}^{J-1} w_j
    = \prod_{s=1}^{J-1}(1-z_s),
$$

so the truncated weights sum to one.

When many DP draws are generated for different values of \(\nu\), the paper
uses a single common \(J\) based on the maximum \(\nu\) across iterations.
The sampling functions accept an optional `n_terms` argument so the caller can
supply that common truncation level.

## 5. Posterior Dirichlet process

After fitting the mixture model, suppose the Gibbs sampler has produced latent
values

$$
\theta_i=(\alpha_i,\lambda_i),\qquad i=1,\dots,n.
$$

The conditional distribution of \(G\) given these values is again a Dirichlet
process:

$$
G\mid \theta,\nu,\gamma,\phi
\sim
\operatorname{DP}\!\left(
(\nu+n)\,
\frac{\nu G_0+\sum_{i=1}^{n}\delta_{\theta_i}}{\nu+n}
\right).
$$

So the posterior DP has precision \(\nu+n\) and base measure

$$
\frac{\nu}{\nu+n}G_0
+
\frac{1}{\nu+n}\sum_{i=1}^{n}\delta_{\theta_i}.
$$

Consequently, each truncated atom is drawn independently from \(G_0\) with
probability

$$
\frac{\nu}{\nu+n},
$$

and otherwise it is one of the observed \(\theta_i\) chosen uniformly. This is
the DP update used in step (i) of Section 3 of the paper.

## 6. Hyperparameters for Section 5.1

The three priors for \(\nu\) used in Section 5.1 are

$$
\nu\sim\operatorname{Gamma}(2,0.9),
\qquad
\nu\sim\operatorname{Gamma}(2,0.1),
\qquad
\nu\sim\operatorname{Gamma}(3,0.05),
$$

where the second parameter is the rate. In NumPy/SciPy this is

```python
nu = rng.gamma(shape=a_nu, scale=1.0 / b_nu)
```

For \(\gamma\) and \(\phi\), the paper takes

$$
a_\gamma=1,
\qquad
a_\phi=2,
$$

and chooses \(b_\gamma,b_\phi\) from a prior guess for the population median
and interquartile range. The induced marginal priors are

$$
[\lambda]=\frac{2b_\gamma}{(1+\lambda b_\gamma)^3},
\qquad
[\alpha]=\frac{2b_\phi^2}{3\max(\alpha,b_\phi)^3}.
$$

Their medians are

$$
\operatorname{median}(\lambda)=\frac{\sqrt{2}-1}{b_\gamma},
\qquad
\operatorname{median}(\alpha)=\frac{3b_\phi}{4}.
$$

Given a Weibull guess with shape \(\tilde\alpha\) and paper-scale
\(\tilde\lambda\), setting the prior medians equal to those values gives

$$
b_\gamma=\frac{\sqrt{2}-1}{\tilde\lambda},
\qquad
b_\phi=\frac{4\tilde\alpha}{3}.
$$

Using the true data-generating mixture in Section 5.1,
\(0.8\,\mathrm{LN}(0,0.25)+0.2\,\mathrm{LN}(1.2,0.02)\), the population
median and IQR are approximately

$$
\text{median}\approx 1.1727,
\qquad
\text{IQR}\approx 1.3679.
$$

Matching a Weibull distribution to those values gives

$$
\tilde\alpha\approx 1.3314,
\qquad
\tilde\lambda\approx 1.7836,
$$

and therefore

$$
b_\gamma\approx 0.2322,
\qquad
b_\phi\approx 1.7752.
$$

If the prior guess is taken from an actual simulated sample instead, use that
sample's median and IQR and recompute. For example, the \(n=200\) sample
generated by `TwoLognormalMix` gives approximately

$$
\tilde\alpha\approx 1.3890,
\qquad
\tilde\lambda\approx 1.6979,
\qquad
b_\gamma\approx 0.2440,
\qquad
b_\phi\approx 1.8520.
$$

## 7. Weibull parameterisation and the median

This is the point that causes the apparent disagreement with the Wikipedia
formula.

The paper uses the parameterisation

$$
K_W(t\mid \alpha,\lambda)
=
1-\exp\!\left(-\frac{t^\alpha}{\lambda}\right).
$$

The standard Weibull parameterisation uses a scale parameter \(c\):

$$
F(t\mid k,c)
=
1-\exp\!\left[-\left(\frac{t}{c}\right)^k\right].
$$

These are the same family, with

$$
k=\alpha,
\qquad
\left(\frac{t}{c}\right)^\alpha
=
\frac{t^\alpha}{c^\alpha}
=
\frac{t^\alpha}{\lambda}.
$$

Therefore

$$
c^\alpha=\lambda
\qquad\Longleftrightarrow\qquad
c=\lambda^{1/\alpha}.
$$

The paper's \(\lambda\) is **not** the standard Weibull scale parameter \(c\).
It is the standard scale raised to the shape power:

$$
\lambda=c^{\alpha}.
$$

The median formulas are consistent:

$$
m
=
\left(\lambda\ln 2\right)^{1/\alpha}
\qquad\text{(paper parameterisation)},
$$

and

$$
m
=
c\left(\ln 2\right)^{1/\alpha}
\qquad\text{(standard parameterisation)}.
$$

Substituting \(c=\lambda^{1/\alpha}\) into the second formula gives

$$
c\left(\ln 2\right)^{1/\alpha}
=
\lambda^{1/\alpha}\left(\ln 2\right)^{1/\alpha}
=
\left(\lambda\ln 2\right)^{1/\alpha},
$$

which is exactly the paper's formula.

Solving for the two scale parameters gives

$$
\lambda=\frac{m^\alpha}{\ln 2}
\qquad\text{(paper parameterisation)},
$$

and

$$
c=\frac{m}{(\ln 2)^{1/\alpha}}
\qquad\text{(standard parameterisation)}.
$$

So the code

```python
lam = median**alpha / np.log(2.0)
```

is correct for the paper's \(\lambda\). The expression

$$
\frac{m}{(\ln 2)^{1/\alpha}}
$$

is correct for the standard Weibull scale \(c\), but it is not the paper's
\(\lambda\). There is no contradiction; the same symbol \(\lambda\) is used for
two different scale conventions.

When using SciPy's `weibull_min`, its `scale` argument is the standard scale
\(c\), so the paper's distribution corresponds to

```python
from scipy.stats import weibull_min

# paper: K_W(t | alpha, lam) = 1 - exp(-t**alpha / lam)
dist = weibull_min(c=alpha, scale=lam ** (1.0 / alpha))
```

## 8. Usage

The module provides:

- `sample_g0` — draws \((\alpha,\lambda)\) from \(G_0\);
- `stick_breaking_weights` — draws truncated stick-breaking weights;
- `truncation_number` — computes \(J\) from the precision and \(\epsilon\);
- `sample_dp_prior` — draws \(G\sim\operatorname{DP}(\nu G_0)\);
- `sample_dp_posterior` — draws \(G\mid\theta,\nu,\gamma,\phi\);
- `DPRealization` — stores a finite \(G\) and provides `cdf`, `survival`,
  `pdf`, and `hazard` summaries;
- `weibull_from_median_iqr` — matches a Weibull to a median and IQR;
- `b_gamma_b_phi_from_weibull` — implements the Section 4.3 prior
  specification.

A minimal prior draw is

```python
from dp_weibull import sample_dp_prior

G = sample_dp_prior(
    nu=2.0,
    gamma=1.0,
    phi=2.0,
    epsilon=1e-4,
)

# G.weights, G.alphas, G.lambdas
# G.survival(t), G.pdf(t), G.hazard(t)
```

A full Section 5.1-style run, which draws \((\nu,\gamma,\phi)\) and then
\(G\), is available by executing

```bash
pixi run python src/dp_weibull.py
```
